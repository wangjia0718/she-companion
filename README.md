# 桌面陪伴（她）

一个跑在 Windows 桌面上的本地虚拟陪伴应用：透明立绘常驻桌面、记得住你说过的事、有自己的日程和日记、形象与模型都由你自己配置。

## 功能

- **跨天记忆**：聊天时按相关度召回记忆卡；每 4 轮（或空闲 10 分钟）用后台模型抽一次；设置里可查、可改、可删，删掉的同主题 30 天内不会再被抽出。
- **桌面小人**：透明无边框、置顶、可拖动、默认鼠标穿透；单击开聊天、双击开设置、右键换形象/看她今天/隐藏。
- **自己过日子**：每周生成一次活动池（20–30 条，按性格/职业硬过滤），每天从池子里本地抽样 3–6 条日程（0 token，条数与时间点由「规律 / 节奏」决定），按点推进本地事件（0 token），默认 21:00 写日记（设置里可改，右侧日记抽屉可回看和删除）；开机、事件、久未联系、生日、节日、项目完成、天气突变、隔天回访、睡前九个触发源会按优先级主动说一句话（每日总数仍受上限约束）。生日当天会多一条 19:30 的「给自己做点特别的」。
- **心情 / 体力 / 专注**：每个角色有自己的状态，跨天会结算（睡一觉回体力、心情向平稳回归）；太累时不出门、也很少主动说话，心情低时每天最多主动说一句；聊天也会顺着状态改变语气。设置 → 生活底部能只读查看。
- **生日与五维性格**：填阳历生日后按星座基准 + 职业/宠物修正算出社交/规律/开放/节奏/表达五维，再生成 5–8 条具体行为描述；设置里可逐项手改，聊天只注入行为与边界，不会提星座。五维都真正作用到行为上：社交/开放决定活动准入（硬门槛），规律决定时间点固定程度（≥70 固定锚点 ±10 分钟、≤30 抖动 ±45 分钟），节奏决定每天条数（≥70 排 5 条并可多一条「顺路」小事、≤30 固定 3 条），表达决定主动消息的字数与频率（≤30 单条 28 字、每天少发一条、不回访；≥70 维持 40 字）。
- **多角色**：可建多个角色，各自独立的记忆、日程、日记与会话，聊天窗左侧切换；新建即生效，不用重启。
- **自定义立绘**：形象包 + 六个帧位（idle / happy / sad / think / angry / sleepy），支持多套形象包与缩放 0.5–2.0。
- **多模型**：任意 OpenAI 兼容 API（chat/completions 流式 + embeddings），可分别指定聊天、后台、向量模型，支持温度、最大 token、连接测试。
- **中英双语**：设置 → 通用 → 界面语言可在「简体中文 / English」之间切换；界面、右键菜单、托盘、系统对话框、聊天与主动消息、日程 / 日记 / 记忆卡等生成内容都跟随语言。切换语言不会翻译或改写已有聊天、日记和日程，旧内容保持原样。

## 安装

需要 Node.js 20 以上（本机 Node 只用来跑 `npm`、测试和脚本；应用运行时是 Electron 自带的 Node）。本项目在 Node v24.19.0 + Electron 33 下验证。

```powershell
npm install
npm start
```

国内网络建议先切镜像，Electron 二进制单独指镜像：

```powershell
npm config set registry https://registry.npmmirror.com
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install
```

仍失败时可临时走代理（只在装依赖时开，跑应用不需要）：

```powershell
$env:HTTP_PROXY="http://192.168.2.253:2080"; $env:HTTPS_PROXY=$env:HTTP_PROXY
```

`npm start` 会打开小人窗、聊天窗和设置窗；关掉聊天/设置不会退出应用，托盘菜单「显示小人 / 打开聊天 / 设置」可再次打开，退出走托盘菜单。

## 首次配置

第一次打开聊天窗，会显示「三步把她接回家」卡片，按顺序完成即可（每步完成会自动打勾）：

1. **填模型**：设置 → 模型，填 `baseUrl`（如 `https://api.deepseek.com/v1`）、`model`、API Key，点「测试连接」确认延迟与模型名；可加多个配置组，分别指定聊天 / 后台 / embedding。
2. **建角色**：设置 → 角色，填名字、性格、说话风格、口癖、背景、关系、边界、喜好；聊天窗左下「＋ 新建角色」也可以。
3. **传立绘**：设置 → 形象，选一张 PNG 传到 `idle` 帧（必需），其余表情可选，缺的会回落到 idle。

立绘要求：

- **必须是 PNG**（JPG/GIF/WebP 请先导出成 PNG），**必须带透明通道**，否则会提示「这张没有透明背景」，不会贴上一块白底。
- 建议最长边 **≤ 2048px**（更大也能用，但动画会变慢；超过 8192px 直接拒绝）。
- 人物建议留少量透明边距，桌面观感更自然；窗口尺寸按图片宽 × 缩放自动适配，高度额外留出气泡位。

## 数据与备份

所有数据都在项目根目录的 `data/`：

```
data/
├─ settings.json                 设置（含明文 API Key）
├─ usage.json                    每日调用次数与 token
├─ characters/<角色 id>/
│  ├─ character.json             人设、形象包与帧位
│  ├─ memory.json                记忆卡与抑制登记表
│  ├─ timeline.json              日程 / 事件 / 日记 / 本周主动日（保留 180 天）
│  ├─ state.json                 当天状态：心情 / 体力 / 专注
│  ├─ chat.jsonl                 会话（一行一条）
│  └─ assets/pack-<包>/...       立绘文件
└─ userData/                     Electron 自己的缓存（可删）
```

- ⚠️ **API Key 以明文保存在 `data/settings.json`**。这是首版的取舍（后续可接系统钥匙串）；不要把 `data/` 上传到公开仓库或发给别人。
- **备份**：直接复制整个 `data/` 目录即可，换机器时放回项目根目录就能接着用。
- **导出**：设置 → 数据 → 「导出全部数据」，选一个目录，会生成 `she-export-<yyyymmdd-HHMM>/` 文件夹（不是 zip）。导出副本里的 `settings.json` 与 `.bak` **已移除 API Key**，可以安全发给别人；原始 `data/` 不会被改动。
- 写入采用「临时文件 + rename」，读取失败会先尝试 `.bak`；主文件与备份都坏时把坏文件改名为 `*.corrupt-<时间戳>` 留证，再用默认值继续，不会静默丢数据。

## 成本控制

默认值都在 `src/main/config.js` 的 `DEFAULT_SETTINGS`，已存在的设置在 `data/settings.json` 里改（改完重启应用）：

| 项目 | 默认 | 含义 | 在哪里改 |
|---|---|---|---|
| `life.proactiveWeekMin` / `proactiveWeekMax` | 0 / 10 | 每周主动消息数量范围（0–63）；每周在范围内按性格 / 关系加权取一个数（0 表示这周不主动），再随机分到若干天：次数少时可能只占一两天、某天连发几条，次数多时才铺满整周；只落在她当天的空闲时段（静默时段除外），间隔 ≥30 分钟，单日上限受可用触发源限制（≤9 条/天，周总量小时 3 条/天） | 设置 → 生活 → 每周主动消息数量范围（两个输入框并排）；或 `settings.json` |
| `life.maxBackgroundCallsPerDay` | 24 | 每天后台调用上限（日程 / 日记 / 主动消息 / 记忆抽取） | 设置 → 生活 → 每日后台调用上限；或 `settings.json` |
| `life.dailyDiscovery` | true | 让模型结合当天日程、天气和状态生成 0–1 件小意外；约 30–70% 的日子有，模型也可以返回空；会多一次后台调用 | `data/settings.json` 的 `life.dailyDiscovery` |
| `memory.extractEveryTurns` | 4 | 累计多少条用户消息抽一次记忆 | 设置 → 生活页不提供该项，改 `data/settings.json` 的 `memory.extractEveryTurns` |
| `life.quietFrom` / `quietTo` | 23:30 / 08:00 | 静默时段，期间不发主动消息 | 设置 → 生活 → 静默时段 |
| `life.diaryHour` | 21 | 每天几点写日记（0–23；app 开着才写） | 设置 → 生活 → 写日记时间；或 `settings.json` |
| `memory.extractIdleMinutes` | 10 | 距最后一条用户消息多久后补抽一次 | `data/settings.json` |

周次数取数不是平均随机：表达欲、社交、节奏越高，关系文案 / 对话历史越亲近，心情 / 体力越好，越容易落在范围偏大的一端；反之更容易取小。生日 / 节日优先占用名额，周内次数固定，不会因为状态变化重新掷骰子。次数会随机落到若干天（不是按天平均），实际发送还受她当天的空闲时段、静默时段和单日触发源上限（最多 9 条/天）限制。

后台预算用完后当天所有后台任务静默跳过（不打扰），次日 00:00 自动重置；设置 → 生活底部能看到「今日后台 n/24 次」。聊天本身不受后台预算限制。

日程侧的成本：活动池每 7 天最多生成一次（一次模型调用），日常抽样 0 次调用；预算不足 / 未配置模型 / 生成失败时用本地兜底池（同样按五维与职业硬过滤），不会退回「每天让模型现编日程」。

## 常用命令

```powershell
npm test                       # node:test 全量单元测试（不启动 Electron）
npm run smoke                  # 冒烟：写 data/smoke 演示数据，三窗口截图后退出
npm run selftest               # 自检：三窗口加载 + preload on/off/脱敏断言
node scripts/e2e-mock.js       # 端到端：本地假模型 + 真实主进程模块跑完整聊天/记忆链路
```

- `npm run smoke` 需要图形环境（Windows 桌面）。成功时退出码 0，并生成：
  - `data/smoke/smoke-pet.png`（220×380，1×1 透明演示帧，画面本身是透明的）
  - `data/smoke/smoke-chat.png`（1100×720）
  - `data/smoke/smoke-settings.png`（1100×720）
- `node scripts/e2e-mock.js` 不启动 GUI、不联网，数据写在系统临时目录并在结束时删除；成功输出 `E2E PASS` + 耗时。

## 已知限制

- **没有语音**：不做 TTS / STT / 通话，只有文字。
- **同义改写可能留成两条记忆**：合并阈值保守（二元组 Jaccard ≥ 0.72 且带否定/加字保护），「下周要交方案」和「下周三交季度方案」可能各存一条；可在记忆列表里手动编辑/删除。
- **单击有 500ms 判定延迟**：为了区分单击开聊天和双击开设置，单击会等 500ms 再执行。
- **多屏拔插后位置会回到可见区**：显示器移除/分辨率变化时，小人窗会被钳制回最近的可用区域，不会留在已消失的屏幕上。
- **单实例**：重复启动只会聚焦已有窗口，不会开第二份。
- **API Key 明文**（见上）；**首次引导不校验图片像素质量**，只校验 PNG 结构与 alpha。
- 透明窗口的鼠标穿透在个别 Windows 缩放/多屏组合下可能异常，可在设置 → 通用里关掉「鼠标穿透」改为整窗可点。

## 开发结构

```
src/main/
  main.js       生命周期、三窗口、托盘、单实例、调度装配、--selftest/--smoke
  config.js     设置默认值、逐字段校验、原子写、脱敏（apiKey 不出主进程）
  store.js      JSON/JSONL 原子读写、.bak 恢复、*.corrupt-* 留证、角色 CRUD
  llm.js        OpenAI 兼容客户端：SSE 流式、embeddings、重试/取消/超时、用量估算
  prompt.js     人格/此刻/记忆/历史/约束的装配与预算裁剪
  memory.js     归一化、相似度、打分检索、合并去重、抽取、抑制、2000 条淘汰
  usage.js      每日调用与 token 记账、后台预算闸门、60 天裁剪
  life.js       日程落盘/校验、活动池接入、事件推进、日记、九源主动消息与模板兜底
  activity.js   活动池：职业判定、准入过滤、兜底池、模型提示词/解析、每日抽样（纯函数）
  state.js      心情/体力/专注：归一化、跨天结算、事件与聊天微调、一句话描述（除读写外纯函数）
  projects.js   长期项目：清洗/推进/完成文案、晚间项目活动时间抖动（纯函数）
  persona.js    星座基准、五维自动计算、内在行为/边界生成与规范化（纯函数）
  scheduler.js  每分钟 tick、重入保护、静默时段、空闲抽取判定
  assets.js     PNG 签名/IHDR/alpha 校验与帧位导入（校验不过不写盘）
  geometry.js   小人位置钳制（多屏 / 缩放 / 拔插）
  ipc.js        IPC 通道表（单一入口，纯函数便于测试）+ 记忆抽取器
  i18n.js       主进程 i18n 包装（共享引擎 + 主进程字典）
  i18n-en.js    主进程英文字典：托盘、系统对话框、兜底日程 / 事件 / 主动消息、错误文案
  content/*.json 静态文案：事件模板、活动细节、类别细节、主动消息兜底、小意外、默认日程
  content/index.js 内容加载：优先读 data/content 覆盖，缺失/格式错回退内置 JSON
src/shared/i18n.js              翻译引擎：字典、占位符、DOM 自动翻译（主进程与渲染层共用）
src/shared/i18n-ui-en.js        渲染层中英字典（设置 / 聊天 / 小人 / 托盘 / 首次引导）
src/preload/preload.js          contextBridge 白名单（通道 + 事件）
src/renderer/pet|chat|settings|shared   经典 script 渲染层，无打包器
scripts/e2e-mock.js             端到端验收（node 直接跑，不启动 GUI）
test/*.test.js                  node:test
```

打包版首次启动会把内置文案复制到 `data/content/*.json`；之后改这些 JSON、重启即可，不需要重新打包。删除 `data/content` 后，下次启动会重新复制内置版本。
